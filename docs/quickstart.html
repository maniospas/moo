🚀 Quickstart

Download the moo executable from the latest release from the GitHub repository. Or clone that repository and run g++ moo.cpp -o moo -Wall -O3 to produce that executable. 
./moo examples/hello.txt.moo
/***file.read examples/hello.txt.moo***/
/***file.read examples/hello.linux.txt.moo***/

Running the above on a Linux OS creates examples/hello.txt (the .moo suffix is stripped):

Hi!
Hello world from a linux file!
- Be safe out there.
